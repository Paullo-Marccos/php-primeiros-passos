# 🐘 Primeiros Passos em PHP

Repositório criado para registrar minha jornada de aprendizado em **PHP**, contendo scripts práticos que envolvem lógica de programação, formulários HTML e manipulação de dados via método POST.

## 📂 O que tem por aqui?

* **Calculadora (`index.php`):** Uma calculadora simples para praticar condicionais (`switch`), operações aritméticas e tratamento de erros (como divisão por zero).
* **Calculador de Média (`media.php`):** Exercício focado na criação e uso de funções personalizadas e formatação de números.
* **Calculador de Idade (`nascimento.php`):** Manipulação de dados de formulário (texto, números e campos de rádio) integrada com funções de data do PHP.

## ▶️ Como executar

Este projeto usa **PHP**, então **não funciona no GitHub Pages**, que hospeda apenas arquivos estáticos. Para testar na sua máquina, use o **XAMPP**:

1. Instale o [XAMPP](https://www.apachefriends.org/) e abra o **XAMPP Control Panel**.
2. Clique em **Start** no módulo **Apache**.
3. Clone o repositório dentro da pasta `htdocs` do XAMPP:
   ```bash
   cd C:\xampp\htdocs
   git clone https://github.com/Paullo-Marccos/php-primeiros-passos.git
   ```
4. Acesse no navegador:
   - Calculadora: `http://localhost/php-primeiros-passos/index.php`
   - Média: `http://localhost/php-primeiros-passos/php/media.php`
   - Idade: `http://localhost/php-primeiros-passos/php/nascimento.php`

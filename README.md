# 🐘 Primeiros Passos em PHP

Repositório criado para registrar minha jornada de aprendizado em **PHP**, contendo scripts práticos que envolvem lógica de programação, formulários HTML e manipulação de dados via método POST[cite: 1, 2, 3].

## 📂 O que tem por aqui?

* **Calculadora (`index.php`):** Uma calculadora simples para praticar condicionais (`switch`), operações aritméticas e tratamento de erros (como divisão por zero)[cite: 1].
* **Calculador de Média (`media.php`):** Exercício focado na criação e uso de funções personalizadas e formatação de números[cite: 2].
* **Calculador de Idade (`nascimento.php`):** Manipulação de dados de formulário (texto, números e campos de rádio) integrada com funções de data do PHP[cite: 3].
